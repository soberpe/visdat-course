# Visualisierung & Datenaufbereitung: Kurs-Site

## Schnellstart
```bash
# 1) Node 18+ installieren
# 2) Abhängigkeiten installieren
npm i

# 3) Entwickeln
npm run start

# 4) Bauen & (optional) deployen
npm run build
# npm run deploy   # GitHub Pages (config in docusaurus.config.js anpassen)
```

## Struktur
- `docs/` - Skript/Handout in Markdown
- `slides/` - Marp-Markdown-Folien
- `data/` - Beispieldatensätze für die Übungen

## Abgaben

Dieses Repository enthält ausschließlich Kursmaterial. Die Abgaben der
Studierenden liegen in einem eigenen privaten Repository pro Jahrgang, damit
personenbezogene Daten nicht öffentlich sind. Der Ablauf ist beschrieben in
`docs/tools-workflow/submission-workflow.md`.
